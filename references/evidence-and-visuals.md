# 证据、计算与图表

只在资料多、计算或图表较复杂时读取相应部分。重要结论应能追溯到最近的来源、记录或计算。

## 证据身份

| 写入报告的内容 | 需要保留的依据 |
| --- | --- |
| 资料事实 | 文献、手册或规范的具体页码、章节或表格；保留适用条件与版本 |
| 实测观察 | 原始数据、记录、照片或日志；注明装置、时间或环境等必要条件 |
| 推导结果 | 输入值、单位、公式、假设及处理步骤 |
| 仿真结果 | 模型、参数、边界条件与输出文件 |
| 设计目标与解释 | 说明其为目标或推断，并给出理由及尚需的验证 |

来源较多时，可复制 [证据表](../assets/evidence-ledger.csv) 到任务目录，记录关键结论、依据位置和条件；简单报告不必创建专门表格。引用应放在对应论断附近，参考文献必须真实且与文内引用对应。改绘和自绘图应标明，不把生成的示意图当成实物照片或实测结果。

## 计算

对影响结论的计算，写清模型、变量与单位、输入来源和假设，再给出结果及合理精度。检查量纲、数量级，以及正文、公式、表格和图中的重复数字是否一致。额定值、理论峰值和仿真值不能直接写成系统的实测性能。

## 图表选择与核对

- 关系和过程用框图或流程图；时间变化用时序图；定量趋势用坐标图；重复参数和方案比较用表格。
- 图题、表题、编号和单位要清楚。正文需说明读者应看哪里、由图表得到什么结论；不要让图表孤立出现。
- 电路、连接、信号方向、时序边沿、坐标和比例具有技术含义时，优先采用可确定位置与数值的绘图工具，并对照来源逐项核对。
- 图中术语、符号和颜色含义与正文一致；不要仅靠颜色区分信息。图像在最终页面尺寸下仍须可读。
