# 报告类型与主线

先看题目要求和证据来源，再决定章节。下面是可选结构，不是统一目录；指定模板优先。

| 类型 | 主要问题 | 适合保留的内容 |
| --- | --- | --- |
| 文献综述或技术调研 | 现有资料如何解释或解决这个问题？ | 范围与检索依据、关键概念、不同观点或方案的比较、适用条件、结论与缺口 |
| 实验报告 | 在什么条件下观察到了什么？ | 目标、原理、装置与条件、步骤、原始数据、处理方法、结果、误差与讨论 |
| 工程设计或项目实现 | 为什么选此方案，如何证明它可行？ | 需求与约束、备选方案、系统结构、关键计算与实现、验证、风险与改进 |
| 数据分析 | 数据如何支持结论？ | 问题、数据来源、清洗与排除、方法、结果、敏感性或稳健性、局限 |

## 组织主线

- 用题目中的核心问题确定全文主张，再为每节分配一个具体任务。背景只保留后文确实要用到的概念。
- 课程要求和评分点是内部核对表。正文应写研究问题、设计目标、方法和证据，不写“为满足老师要求”一类制作说明。
- 文献类要综合来源并指出差异，不能依次复述每篇文献；设计类要说明取舍，不能只罗列功能；实验类要让读者看得出结果从哪些记录得到。
- 结论回答开头提出的问题，并保留关键条件与局限。没有足够证据时，用“模型预计”“仍待实测”等准确表述。

## 篇幅取舍

先保证必写内容与关键论证，再压缩重复背景。页数或字数是约束，不是填充目标。摘要、目录、附录、关键词等按题目或文档体量决定；不要为了显得完整而机械加入。
